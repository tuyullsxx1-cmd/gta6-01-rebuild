# MARAVILLA — One Last Score (Realistic Rebuild)

An open-world coastal city game built with Three.js: 10 story missions, 5 vehicles, a 5-star wanted system with responsive police, traffic and pedestrians, a full HUD with minimap, and a save system. Explore six districts, from the Marina to Downtown Plaza, and pull off one last score at the Grand Maravilla casino.
